## Para quem conduz (não entregar esta parte)

**Texto dos itens:** copiado da versão brasileira validada por Lourenço, Carmona e Lopes (2022), Tabela 1. Não altere a redação, para que a validação continue valendo (no item 9, mantenha "seguro" mesmo com participante mulher).

**Cálculo da nota (0 a 100), segundo Brooke (1996):** itens ímpares valem (nota − 1); itens pares valem (5 − nota). Some os 10 valores e multiplique por 2,5. A aba SUS da `planilha_registro.xlsx` faz a conta sozinha:

`((Q1−1) + (5−Q2) + (Q3−1) + (5−Q4) + (Q5−1) + (5−Q6) + (Q7−1) + (5−Q8) + (Q9−1) + (5−Q10)) × 2,5`

Exemplo: notas 4, 2, 4, 1, 4, 2, 5, 2, 4, 2 → (3+3+3+4+3+3+4+3+3+3) × 2,5 = **80,0**. Brooke avisa que a nota de cada item sozinho não tem significado: só o total.

**Leitura:** a nota não é uma porcentagem. Com 5 participantes, a média serve só como indicação; o mais útil são os problemas observados durante as tarefas.
